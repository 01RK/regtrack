# 文件管理

顶栏「文件管理」选择标准或工作组。每个标准按完整生命周期阶段及「其他」隔离，每个工作组有独立空间。标准详情和工作组字典有快捷入口。

支持多文件依次上传、中文名下载、新建子文件夹、分页浏览、删除文件与递归删除子文件夹。同名文件默认拒绝，确认覆盖后替换；取消则跳过该文件继续上传。阶段根目录与工作组根目录是固定入口，不能删除。

覆盖操作在提交前保留旧文件，失败时清理新对象；删除操作在数据库提交成功后清理对象。删除标准前显示包括阶段与其他文件在内的影响数量。有文件的工作组不能删除，也不能通过字典替换导入删除；可以停用该工作组。

上传请求上限由服务器 REGTRACK_MAX_UPLOAD_MB 设置，默认 100 MB（含请求开销）。文件名不允许路径分隔符、控制字符及 Windows 禁用字符。文件上传者用于署名；访问认证由服务器入口处理。

业务数据交换包含草案附图，不包含文件管理中的通用文件。完整备份需要数据库和对象桶配对备份，见 DEPLOYMENT_ZH.md。
