# 消息中心设计（fix1.5）

消息中心增加卡片首页：铃铛 → 消息中心 → 最新标准进度 → 分类消息。当前将所有标准进度归为一张卡片，展示总待处理数及三类数量；后续其他消息板块从同层卡片进入。详情页提供返回消息中心的链接。

标准进度板块按业务栏目组织：计划下达、征求意见更新、标准公告更新、全部动态。分类页是工作队列，全部动态是完整记录。去掉未读动态标签页及批量已读操作，采集成功不生成消息。

已有标准采集后立即更新；消息是知悉事项而非更新审批。逐条「我已知悉」才从分类队列移除，右上角数字相应减一。未建档计划保留确认追踪与本次忽略；确认按立项建档，忽略后下次采集可再次提醒。

消息采用紧凑行式布局，类别、标题、状态及编号、通知日期按列对齐；右侧固定三列，主按钮（确认追踪／我已知悉）、辅助操作（本次忽略／标准档案）、来源详情对应同列，按钮同宽；行间细分隔线、活动项左侧强调色，减少纵向占用。长标题自然换行，窄窗口操作行下移。

采集设置默认开启。范围控件使用已有 Tom Select，下拉菜单内部输入自定义天数并直接选用，关闭时只保留一行选定范围，无外置输入框。

完整业务规则和验证方法见 [CATARC_COLLECTION.md](CATARC_COLLECTION.md)。
